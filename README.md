# UFO Atelier - Главная страница (MVC)

Проект содержит стартовую главную страницу для магазина премиальных светильников в стиле сдержанной luxury-подачи.

## Что реализовано

- MVC-структура на `Express + EJS`
- Главная страница с акцентом на витрину продуктов и точку контакта
- Заглушки для нереализованных разделов:
  - `/catalog`
  - `/projects`
  - `/designers`
  - `/about`
  - `/contacts`
- Заглушки для текстов, изображений и формы отправки
- Адаптивная верстка (desktop + mobile)

## Обязательные действия с вашей стороны

1. Установить **Node.js 18+** (если еще не установлен).
2. Установить зависимости проекта:

```bash
npm install
```

3. Запустить сайт локально:

```bash
npm run dev
```

4. Открыть в браузере:

```text
http://localhost:3000
```

## Где редактировать контент

- Главные данные и списки продуктов: `src/models/productCatalogModel.js`
- Логика рендеринга страниц: `src/controllers/homeController.js`
- Роутинг: `src/routes/webRoutes.js`
- Главная страница: `src/views/home/index.ejs`
- Шаблон заглушек: `src/views/placeholders/page.ejs`
- Стили: `public/css/styles.css`
- Скрипты интерфейса: `public/js/main.js`

## Важно про фото и тексты

- Сейчас используются изображения-заглушки (`picsum.photos`).
- Чтобы перейти к финальному виду, замените URL изображений в `src/models/productCatalogModel.js` на ваши реальные фото/рендеры.
- Все тексты вида `[Текст-заглушка]` рассчитаны на быструю замену на финальный copy.
